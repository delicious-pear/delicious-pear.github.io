# 常见问题 FAQ

这里整理班级同学高频遇到的问题，避免重复提问。点击问题即可展开答案。

::: tip 提示
答案可能随政策变化，请以学院最新通知为准。有更新请直接在 GitHub 上编辑此页。
:::

## 选课与培养

<details>
<summary>如何查询本专业培养方案和学分要求？</summary>

登录浙江大学教务系统，在「培养方案」模块查看本专业培养计划与学分结构；也可咨询班主任或教务老师确认选课学分是否满足毕业要求。
</details>

<details>
<summary>选课冲突 / 退改选怎么处理？</summary>

按教务系统选课通知的时间窗口操作退改选；如遇系统问题或特殊原因，联系学院教务办公室处理。
</details>

## 考试与成绩

<details>
<summary>缓考、补考、成绩复核怎么申请？</summary>

按学校考试管理规定，在指定时间内向学院教务提交缓考/成绩复核申请，具体材料与截止时间以教务处通知为准。
</details>

## 请假与日常

<details>
<summary>请假流程是什么？</summary>

一般需提前向班主任/辅导员请假，必要时提交书面假条；实习、外出等长时间离校还需按学院要求报备。具体模板见「资料共享 → 通用资料」。
</details>

## 校园生活

<details>
<summary>校园网 / 一卡通 / 宿舍报修找谁？</summary>

- 校园网：信息技术中心服务热线或在线工单。
- 一卡通：校园卡服务中心。
- 宿舍报修：后勤报修平台或宿管处。

具体入口以学校后勤/信息中心官网为准。
</details>

## 就业与深造

<details>
<summary>保研、考研、出国相关信息和材料在哪看？</summary>

关注学院学工办/教务通知与年级群公告；相关材料模板可在「资料共享」中查找或向辅导员咨询。
</details>
